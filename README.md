# Heart Attack Risk Prediction Using Machine Learning

## Project Overview

This project reproduces the experiments reported in the reference paper on myocardial infarction risk prediction using supervised and unsupervised machine learning methods.

The project consists of two parts:

### Part 1 — Reproduction

Reproduce the dataset preprocessing, unsupervised learning, supervised learning models, evaluation metrics, and reported results from the reference paper.

### Part 2 — Extension

Extend the reference experiment by adding XGBoost and comparing its performance with the models used in the reference paper.

## Dataset

Heart Attack Analysis & Prediction Dataset.
